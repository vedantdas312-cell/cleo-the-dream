# Record decisions
Use only the transcript, messages or notes actually available for this matter. Record the source, speaker if known, time if available, clause, document revision and exact statement.
Classify each item as proposed, explicitly assented to, user-confirmed drafting instruction, unresolved or superseded. Distinguish a person's reported account from direct evidence.
Silence, a summary and a vague acknowledgement are not assent. Conflicting terms remain unresolved. Ask a focused clarification where needed.
Before creating redlines, map a user-confirmed drafting instruction to a unique current source excerpt and recheck the source version. Show original and proposed wording with the evidence behind the change.
Keep private preparation separate from shared meeting content. A one-off compromise does not become a permanent preference. Do not claim persistent memory or meeting access unless those tools actually confirm it.
